# DMeloper's Block Pet

한국어 · [English](README.md)

[![Release](https://raw.githubusercontent.com/d-meloper/dmelopers-block-pet/badges/release.svg)](https://github.com/d-meloper/dmelopers-block-pet/releases/latest) [![Downloads](https://raw.githubusercontent.com/d-meloper/dmelopers-block-pet/badges/downloads.svg)](https://github.com/d-meloper/dmelopers-block-pet/releases) [![Stars](https://raw.githubusercontent.com/d-meloper/dmelopers-block-pet/badges/stars.svg)](https://github.com/d-meloper/dmelopers-block-pet/stargazers) [![License](https://raw.githubusercontent.com/d-meloper/dmelopers-block-pet/badges/license.svg)](LICENSE)

키보드와 마우스에 반응하는 Minecraft 스타일의 데스크톱 펫입니다. 스킨 닉네임을 입력하거나 스킨 이미지 파일을 첨부해 원하는 펫을 적용할 수 있습니다.


## 주요 기능

- 키보드와 마우스 입력에 반응하는 펫
- 64x64 PNG 스킨 이미지 파일과 Minecraft Java Edition 닉네임으로 스킨 적용하기
- 다양한 설정과 스킨을 프리셋으로 쉽고 간편하게 관리하기
- OBS와 연동해 펫을 방송으로 송출하기

## 다운로드

Microsoft Store 배포를 준비하고 있습니다. 앱을 사용할 수 있게 되면 Store 링크를 안내하겠습니다.

GitHub 설치파일은 [릴리즈 페이지](https://github.com/d-meloper/dmelopers-block-pet/releases)에 제공할 예정입니다. 아직 정식 버전은 게시하지 않았습니다.

`.exe` 파일을 실행하면 앱을 설치할 수 있습니다. 함께 제공하는 `.sig` 파일은 파일 검증용이므로 내려 받지 않아도 됩니다.

## 권장 환경

- Windows 11 24H2(빌드 26100) 이상, x64
- Microsoft WebView2 Runtime. 설치되어 있지 않으면 앱이 시작될 때 Microsoft 설치 페이지를 안내합니다.

## 기본 사용법

1. 설치파일을 실행해 앱을 설치하세요.
2. 설정을 열어 스킨을 바꾸고 펫과 장면을 변경하세요.
3. 다시 사용하고 싶은 설정은 프리셋으로 저장하세요.
4. OBS에서 사용하려면 방송 출력을 켜고 연결 주소를 브라우저 소스에 추가하세요. 연결 주소는 다른 사람에게 공개하지 마세요.


공식 GitHub판과 Microsoft Store판은 설정·프리셋·스킨을 공유합니다. 기본 제거에서는 이 데이터를 유지합니다. GitHub 제거기는 기본으로 선택되지 않은 `모든 개인 설정 및 파일 제거` 항목을 제공합니다. 이 항목을 선택하고 확인하면 두 버전이 공유하는 설정·프리셋·스킨도 삭제됩니다. 설치와 복구 방법은 [지원 안내](docs/SUPPORT.ko-KR.md)를 확인하세요.
