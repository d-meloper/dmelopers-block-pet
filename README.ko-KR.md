# DMeloper's Block Pet

[![Release](https://raw.githubusercontent.com/d-meloper/dmelopers-block-pet/badges/release.svg)](https://github.com/d-meloper/dmelopers-block-pet/releases/latest) [![Downloads](https://raw.githubusercontent.com/d-meloper/dmelopers-block-pet/badges/downloads.svg)](https://github.com/d-meloper/dmelopers-block-pet/releases) [![Stars](https://raw.githubusercontent.com/d-meloper/dmelopers-block-pet/badges/stars.svg)](https://github.com/d-meloper/dmelopers-block-pet/stargazers) [![License](https://raw.githubusercontent.com/d-meloper/dmelopers-block-pet/badges/license.svg)](LICENSE)

키보드·마우스 반응, PNG 스킨, 프리셋과 선택적 OBS 브라우저 출력을 제공하는 무료 Minecraft 스타일 데스크톱 펫입니다. 한국어와 영어를 제공하는 독립 개인 프로젝트입니다.

현재는 소스 미리보기 단계이며 공식 설치파일과 Microsoft Store 제품은 아직 공개하지 않았습니다. 아래 배포판 동작은 이 소스의 구현을 설명하며 지금 받을 수 있는 릴리즈를 뜻하지 않습니다.

Windows 11 24H2 이상 x64를 지원합니다. Microsoft WebView2가 필요하며 없으면 앱과 설치기가 Microsoft 수동 설치 페이지를 안내합니다.

출시 후에는 Microsoft Store 설치를 권장하며 실제 설치가 가능해지면 이곳에 직접 링크를 추가합니다. GitHub 설치파일과 분리 서명 `.sig`는 [공식 Releases](https://github.com/d-meloper/dmelopers-block-pet/releases)에 별도로 공개할 예정입니다. GitHub판은 설정을 열 때 업데이트를 확인하고 사용자가 눌러야 설치합니다. Store판 업데이트는 Windows가 관리합니다. 공식 설치끼리 설정·프리셋·스킨을 공유하며 제거해도 보존합니다. 설치·복구는 [지원 안내](docs/SUPPORT.ko-KR.md), 서명·게시자 정보는 [보안 안내](docs/SECURITY.ko-KR.md)를 확인하세요.
