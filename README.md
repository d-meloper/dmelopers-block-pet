A Minecraft-style desktop pet that reacts to your keyboard and mouse. Customize your pet by entering a Minecraft nickname or selecting a skin image file.

## Main Features

- Keyboard and mouse reactions.
- Apply skins using 64x64 PNG images or Minecraft Java Edition nicknames.
- Easily manage your settings and skins with presets.
- Bring your pet into your stream with OBS.

## Download

Microsoft Store distribution is being prepared. The Store link will be added when the app becomes available.

GitHub installers will be available on the [Releases page](https://github.com/d-meloper/dmelopers-block-pet/releases). No official release has been published yet.

Run the `.exe` file to install the app. The accompanying `.sig` file is for verification, so you do not need to download it.

## Recommended Environment

- Windows 11 24H2 (build 26100) or newer, x64.
- Microsoft WebView2 Runtime. If it is missing, the app directs you to Microsoft's installation page when it starts.

## Basic Usage

1. Run the installer to install the app.
2. Open Settings to change the skin, pet and scene.
3. Save settings you want to reuse as a preset.
4. To use the pet in OBS, enable broadcast output and add the connection address as a browser source. Keep this address private.

Official GitHub and Microsoft Store installations share settings, presets and skins. A normal uninstall keeps this data. The GitHub uninstaller has an unchecked “Remove all personal settings and files” option; selecting and confirming it also deletes the shared settings, presets and skins used by both editions. See [Support](docs/SUPPORT.md) for installation and repair.
