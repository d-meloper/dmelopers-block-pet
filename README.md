# DMeloper's Block Pet

[![Release](https://raw.githubusercontent.com/d-meloper/dmelopers-block-pet/badges/release.svg)](https://github.com/d-meloper/dmelopers-block-pet/releases/latest) [![Downloads](https://raw.githubusercontent.com/d-meloper/dmelopers-block-pet/badges/downloads.svg)](https://github.com/d-meloper/dmelopers-block-pet/releases) [![Stars](https://raw.githubusercontent.com/d-meloper/dmelopers-block-pet/badges/stars.svg)](https://github.com/d-meloper/dmelopers-block-pet/stargazers) [![License](https://raw.githubusercontent.com/d-meloper/dmelopers-block-pet/badges/license.svg)](LICENSE)

A free Minecraft-style desktop pet with keyboard and mouse reactions, PNG skins, presets and optional OBS browser output. An independent personal project, available in Korean and English.

This is a source preview. Official installers and the Microsoft Store listing have not been published yet. The channel behavior below describes this source implementation, not an available release.

Supports Windows 11 24H2 or newer, x64. Microsoft WebView2 is required; the app and installer guide you to Microsoft's manual installation page if it is missing.

Microsoft Store will be the recommended installation channel when released; its direct listing link will be added when installation is available. The GitHub installer and its detached `.sig` will be published separately in [official Releases](https://github.com/d-meloper/dmelopers-block-pet/releases). GitHub updates are checked when Settings opens and installed only after your click. Store updates are managed by Windows. Settings, presets and skins are shared between the official installations and preserved on uninstall. See [Support](docs/SUPPORT.md) for installation and repair, and [Security](docs/SECURITY.md) for signature and publisher information.
