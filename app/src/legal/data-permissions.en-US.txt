This policy explains the information processed by DMeloper's Block Pet for Windows, why it is used, and how it is retained and deleted. It applies to the Microsoft Store and official GitHub editions. Update and uninstall procedures differ between editions.
■ 1. Basic Principles and Purposes of Processing
Block Pet is a desktop pet app that reacts to your keyboard and mouse. It processes information needed for input reactions, applying skins, saving settings and presets, optional OBS output, picking screen colors, troubleshooting, and updates.
The app does not offer its own account registration, advertising, usage analytics, or automatic crash-report uploads. It does not automatically upload saved settings or skins to the developer. Features that use the network and inquiries you choose to send are explained separately below.
■ 2. Keyboard and Mouse Input and Screen Color Picking
The app detects key presses and releases, pointer position, mouse buttons, and scrolling to move the pet. Currently pressed keys and input states are held in memory while displaying the movements. Typed sentences and input history are not saved to files or sent to the developer. Turning off Use Mouse hides the mouse object and disables click and scroll reactions, but the pet continues to follow the cursor with its eyes. All input detection stops when you fully quit the app.
When you use the screen color picker, the app temporarily captures an image of your desktop in memory so you can select a color. The captured image is not saved to a file or sent over the network. Capture resources are released when you finish or cancel the selection. The selected color may be saved in the appearance settings you apply.
■ 3. Skins, Usernames, Settings, and Presets
A PNG skin you select is read on this computer, and a copy and preview are saved in the Skin Library. Its display name, original filename when available, arm model, and appearance settings may also be saved. Selecting a local PNG does not upload the file to an external service.
When you use Minecraft Java Edition username lookup, the entered username is sent to api.minecraftservices.com (http://api.minecraftservices.com/) or the fallback service api.mojang.com. The returned public profile ID is queried at sessionserver.mojang.com, and the skin image is downloaded from textures.minecraft.net. These services receive the request details and the network address used for the connection. If you use a proxy, its address may be sent instead. The external services’ privacy policies apply. The app does not request Minecraft, Microsoft, or Xbox sign-in passwords or authentication tokens.
Retrieved skin images and usernames are saved locally for use the next time you run the app. Skins that are not currently in use may remain in the library. A separate cache of downloaded original PNGs is limited to 32 MiB. Saved usernames are not automatically looked up again when the app starts.
When you export a preset, the .petpreset file may include its name, pet, scene, and object settings, and, depending on the export method, a skin image and linked username. Export creates a local file and does not upload it to the developer. Importing a preset shared by username performs one skin lookup and saves the image locally for later use. Before sharing a preset file with someone else, check the images and usernames it contains.
■ 4. Optional OBS Browser Output
OBS output is off by default. When you enable it, an HTTP/WebSocket service opens only on 127.0.0.1 on this computer. It sends the current scene, active PNG skin, and movement events to Browser Sources using the app’s connection URL.
Movement events include physical key positions, press/release states, and timing. A person or local program with the connection URL may be able to infer pressed keys or input activity from these events. Typed sentences, Skin Library names, and other files are not transmitted. Any subsequent recording or internet broadcast is managed by OBS or another program you configure.
The connection URL contains a random access token. Copying the URL writes it to the Windows clipboard, so keep it private. The connection port and token are stored locally to preserve the OBS source URL and are retained after resetting the app. Resetting the app turns off OBS output. Hiding the desktop pet does not stop OBS output while it is enabled. Turning off output in the settings disconnects connected sources.
■ 5. Diagnostic Records, Clipboard, and Updates
New local diagnostic records created by the current version contain warning/error categories, operation names, error codes, limited source locations, timestamps, app version, run type, and process ID. Normal input activity is not recorded. New diagnostic records do not include original error messages, settings, personal file paths, skins, usernames, or OBS connection URLs. Records from earlier versions may remain.
Diagnostic files are kept locally. They are not automatically uploaded or deleted when the app quits or is reset. Before sharing logs, review what you intend to share. Clicking the App Info copy button writes the app and runtime versions and operating system information to the Windows clipboard.
Updates for the Microsoft Store edition are managed by Windows and the Microsoft Store. The Open Microsoft Store button connects to Microsoft services through the Microsoft Store app. The Store edition does not look up GitHub update information or GitHub version-display information.
The official GitHub edition retrieves signed update information from the official GitHub repository when you open settings or request an update check. If you choose to install an update, it downloads a verified installer from the official GitHub release. GitHub receives the request and network address. The app does not include settings, skins, input history, OBS connection URLs, or device identifiers in these requests. Check results and error timestamps are stored locally.
If WebView2 Runtime 120 or later is missing, the official GitHub edition’s WiX installer runs the included Microsoft-signed installation tool. This tool downloads and installs the runtime from Microsoft services, which receive the request and network address. An internet connection is required. The app itself does not download or run the installation tool. If the runtime is unavailable in the Store edition or after installation, the app provides manual installation instructions. The shared WebView2 Runtime is not removed when you uninstall Block Pet.
Information processing by the Microsoft Store, Windows, WebView2, websites you open, and email services is subject to each provider’s policies and your settings. If automatic backup is enabled in Windows, app data may be backed up according to operating system settings. This option alone does not guarantee backup or restoration of all shared Saved Games data.
■ 6. Storage Locations, Retention, and Deletion
The official Microsoft Store and GitHub editions share settings, presets, and the Skin Library in the DMeloper's Block Pet folder under Windows Saved Games. Logs, caches, and WebView data are stored in a separate app data location for each installation. Skins, previews, filenames, usernames, and settings are treated as personal data.
This local data is retained to maintain functionality and for your next session. It may remain until you remove the items or delete the relevant data. Resetting the app alone does not delete all diagnostic logs or the OBS connection port and token. Switching to the default skin does not delete the entire saved Skin Library.
When you uninstall the Microsoft Store edition, Windows manages removal of package-specific data, but shared data outside the package in Saved Games remains. A normal uninstall of the GitHub edition also preserves shared data. Selecting Remove all personal settings and files in the GitHub uninstaller deletes shared Saved Games data and the GitHub edition’s local and roaming app data. This also affects shared settings, presets, and skins used by any remaining Store installation.
To delete shared data yourself, fully quit both apps and delete the DMeloper's Block Pet folder in Windows Saved Games. Deleting this data makes your saved settings, presets, and skins unavailable. If you need help identifying the deletion scope or folder, contact the address below.
■ 7. Information Requests and Your Choices
You can use the app with local PNGs or the default skin without using username lookup or OBS output. OBS output can be turned off in the settings. Turning off Use Mouse hides the mouse object and disables click and scroll reactions, but the pet continues to follow the cursor with its eyes. Fully quit the app to stop all input detection. You can export saved presets to local files or delete the relevant local data.
The developer does not remotely access or change the app’s saved settings or skins. Send privacy-related access, correction, or deletion requests and inquiries to the email address below. Local data that the developer does not hold must be managed on your computer; the developer can explain how to do this.
If you contact the developer by email, the developer receives your email address, inquiry, and any materials you voluntarily attach. This information is used only as needed to respond to your inquiry and process your request, and is retained for as long as processing requires. Information is deleted when its purpose has ended, except where applicable laws require retention for a specified period. Do not send passwords, authentication tokens, OBS connection URLs, or other information unnecessary for your request.
If you use the separate Notion contact form (https://aismash.notion.site/5402dc0bb4ae83fdb83681271f4b937e?pvs=105), your inquiry type, details, system information, optional email address, attachments, and submission time are stored in Notion. Collected email addresses are deleted after the reply is sent, as stated on the form. Inquiries are managed privately. For details about what is collected and how it is cleaned up, see the contact form data section in Data Management Guide (https://aismash.notion.site/3f32dc0bb4ae80808222e5e0cf123464).
