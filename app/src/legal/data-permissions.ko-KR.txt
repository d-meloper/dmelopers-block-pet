DMeloper's Block Pet 개인정보 처리방침

최신 온라인 안내: 개인정보 처리방침 (https://aismash.notion.site/3f12dc0bb4ae809fb5becfc2376d4a5c)

이 방침은 Windows용 DMeloper's Block Pet이 처리하는 정보, 이용 목적, 보관 및 삭제 방법을 설명합니다. Microsoft Store판과 정식 GitHub판에 적용되며, 배포판에 따라 업데이트 및 제거 방식에 차이가 있습니다.
■ 1. 기본 원칙과 정보 이용 목적
Block Pet은 키보드와 마우스에 반응하는 데스크톱 펫 앱입니다. 입력 반응, 스킨 적용, 설정과 프리셋 저장, 선택적 OBS 출력, 화면 색상 선택, 오류 확인 및 업데이트에 필요한 정보를 처리합니다.
앱은 자체 계정 가입, 광고, 사용 분석 또는 충돌 보고서 자동 업로드 기능을 제공하지 않습니다. 저장한 설정과 스킨을 개발자에게 자동으로 업로드하지 않습니다. 네트워크를 사용하는 기능과 사용자가 직접 보내는 문의는 아래에서 별도로 설명합니다.
■ 2. 키보드·마우스 입력과 화면 색상 선택
앱은 펫을 움직이기 위해 키를 누르고 떼는 동작, 포인터 위치, 마우스 버튼과 스크롤을 감지합니다. 현재 눌린 키와 입력 상태는 동작을 표현하는 동안 메모리에서 관리합니다. 입력한 문장이나 입력 이력을 파일로 저장하거나 개발자에게 전송하지 않습니다. 마우스 사용을 끄면 마우스 물체와 클릭·스크롤 반응이 꺼지지만, 커서를 따라보는 동작은 유지됩니다. 앱을 완전히 종료하면 모든 입력 감지가 중단됩니다.
사용자가 화면 색상 선택 기능을 실행하면 데스크톱 화면의 이미지를 메모리에 일시적으로 캡처하여 색상을 고를 수 있게 합니다. 캡처 이미지는 파일로 저장하거나 네트워크로 전송하지 않습니다. 선택을 완료하거나 취소하면 캡처 자원을 해제합니다. 선택한 색상은 사용자가 적용한 외형 설정에 저장될 수 있습니다.
■ 3. 스킨·닉네임·설정·프리셋
사용자가 선택한 PNG 스킨은 이 컴퓨터에서 읽어 복사본과 미리보기를 스킨 목록에 저장합니다. 표시 이름, 확인 가능한 원래 파일명, 팔 모델과 외형 설정도 저장할 수 있습니다. 로컬 PNG 선택만으로 파일이 외부 서비스에 업로드되지는 않습니다.
Minecraft Java Edition 닉네임 조회를 사용하면 입력한 닉네임을 api.minecraftservices.com (http://api.minecraftservices.com/) 또는 대체 경로인 api.mojang.com으로 전송합니다. 반환된 공개 프로필 ID를 sessionserver.mojang.com에서 조회하고, textures.minecraft.net에서 스킨 이미지를 다운로드합니다. 해당 서비스는 요청 내용과 접속에 사용한 네트워크 주소를 받습니다. 프록시 사용 시 프록시 주소가 전달될 수 있으며, 외부 서비스의 개인정보 처리방침이 적용됩니다. 앱은 Minecraft·Microsoft·Xbox의 로그인 비밀번호나 인증 토큰을 요구하지 않습니다.
확인한 스킨 이미지와 닉네임은 다음 실행에서 다시 사용할 수 있도록 로컬에 저장합니다. 현재 사용하지 않는 스킨도 목록에 남을 수 있습니다. 다운로드한 원본 PNG의 별도 캐시는 최대 32 MiB이며, 앱 시작 시 저장된 닉네임을 자동으로 다시 조회하지 않습니다.
프리셋을 내보내면 이름, 펫·장면·오브젝트 설정, 내보내기 방식에 따른 스킨 이미지와 연결된 닉네임이 .petpreset 파일에 포함될 수 있습니다. 내보내기는 로컬 파일을 만들며 개발자에게 업로드하지 않습니다. 닉네임 방식의 프리셋을 가져오면 스킨 조회를 한 번 수행하고 이후 사용할 이미지를 로컬에 저장합니다. 사용자가 프리셋 파일을 다른 사람에게 공유할 경우에는 포함된 이미지와 닉네임을 먼저 확인해야 합니다.
■ 4. 선택적 OBS 브라우저 출력
OBS 출력은 기본으로 꺼져 있습니다. 사용자가 켜면 이 컴퓨터의 127.0.0.1에만 HTTP/WebSocket 서비스가 열리고, 앱의 연결 주소를 사용하는 브라우저 소스에 현재 장면, 활성 PNG 스킨과 동작 이벤트를 전달합니다.
동작 이벤트에는 물리적인 키 위치, 누름·뗌 상태와 타이밍 등이 포함됩니다. 연결 주소를 가진 사람이나 로컬 프로그램은 이 이벤트로 누른 키 또는 입력 활동을 추정할 수 있습니다. 입력한 문장, 스킨 목록 이름이나 다른 파일은 전달하지 않습니다. 이후 녹화나 인터넷 방송은 사용자가 설정한 OBS 등의 프로그램이 관리합니다.
연결 주소에는 임의 접근 토큰이 포함됩니다. 주소 복사 시 Windows 클립보드에 기록되므로 주소를 비공개로 관리해야 합니다. 연결 포트와 토큰은 OBS 소스 주소를 유지하기 위해 로컬에 저장하며, 앱 초기화 후에도 유지합니다. 앱 초기화 시 OBS 출력은 꺼집니다. 데스크톱 펫을 숨겨도 켜져 있는 OBS 출력은 계속되며, 설정에서 출력을 끄면 연결된 소스가 끊깁니다.
■ 5. 진단 기록·클립보드·업데이트
현재 버전에서 새로 작성하는 로컬 진단 기록에는 경고·오류 분류, 동작 이름, 오류 코드, 제한된 소스 위치, 시각, 앱 버전, 실행 유형과 프로세스 ID가 포함됩니다. 정상적인 입력 활동은 기록하지 않습니다. 원문 오류 메시지, 설정, 개인 파일 경로, 스킨, 닉네임과 OBS 연결 주소를 새 진단 기록에 넣지 않습니다. 이전 버전의 기록은 남아 있을 수 있습니다.
진단 파일은 로컬에 보관하며 자동으로 업로드하거나 종료·초기화 시 삭제하지 않습니다. 사용자가 로그를 공유하는 경우 공유할 내용을 먼저 확인해야 합니다. 앱 정보 복사 버튼을 누르면 앱·런타임 버전과 운영체제 정보를 Windows 클립보드에 기록합니다.
Microsoft Store판은 Windows와 Microsoft Store가 업데이트를 관리합니다. Store 열기 버튼은 Microsoft Store 앱을 통해 Microsoft 서비스에 연결합니다. Store판은 GitHub 업데이트 정보나 GitHub 버전 표시 정보를 조회하지 않습니다.
정식 GitHub판은 설정을 열거나 사용자가 업데이트 확인을 요청할 때 공식 GitHub 저장소의 서명된 업데이트 정보를 조회합니다. 업데이트 설치를 선택하면 공식 GitHub 릴리스에서 검증된 설치 파일을 다운로드합니다. GitHub는 요청과 네트워크 주소를 받으며, 앱은 해당 요청에 설정, 스킨, 입력 이력, OBS 연결 주소나 장치 식별자를 넣지 않습니다. 확인 결과와 오류 시각은 로컬에 보관합니다.
정식 GitHub판의 WiX 설치 프로그램은 WebView2 Runtime 120 이상이 없으면 포함된 Microsoft 서명 설치 도구를 실행합니다. 이 도구는 Microsoft 서비스에서 런타임을 내려 받아 설치하며, Microsoft 서비스는 요청과 네트워크 주소를 받습니다. 이 과정에는 인터넷 연결이 필요합니다. 앱 자체는 설치 도구를 내려 받거나 실행하지 않습니다. Store판이나 설치 후에도 런타임을 사용할 수 없는 경우 앱이 수동 설치 안내를 제공합니다. 공용 WebView2 Runtime은 Block Pet을 제거해도 함께 삭제하지 않습니다.
Microsoft Store, Windows, WebView2, 사용자가 여는 웹사이트 및 이메일 서비스의 자체 정보 처리는 각 제공자의 정책과 사용자 설정에 따릅니다. Windows에서 자동 백업을 사용하는 경우 운영체제 설정에 따라 앱 데이터가 백업될 수 있습니다. 이 옵션만으로 공유 Saved Games 데이터 전체의 백업·복원이 보장되지는 않습니다.
■ 6. 저장 위치·보관 기간·삭제
정식 Microsoft Store판과 GitHub판은 Windows의 Saved Games 아래 DMeloper's Block Pet 폴더에서 설정, 프리셋과 스킨 목록을 공유합니다. 로그, 캐시와 WebView 데이터는 각 설치의 별도 앱 데이터 위치에 저장합니다. 스킨, 미리보기, 파일명, 닉네임과 설정은 개인 데이터로 취급합니다.
이 로컬 데이터는 기능 유지와 사용자의 다음 실행을 위해 보관하며, 항목 제거 또는 관련 데이터 삭제 전까지 남을 수 있습니다. 진단 로그와 OBS 연결 포트·토큰은 앱 초기화만으로 모두 삭제되지 않습니다. 기본 스킨으로 변경해도 저장된 스킨 목록 전체가 삭제되지는 않습니다.
Microsoft Store판을 제거하면 Windows가 패키지 전용 데이터를 관리해 제거하지만, 외부 Saved Games의 공유 데이터는 남습니다. GitHub판의 일반 제거도 공유 데이터를 보존합니다. GitHub 제거기의 선택 항목인 모든 개인 설정 및 파일 제거를 사용하면 공유 Saved Games 데이터와 GitHub판의 로컬·로밍 앱 데이터를 삭제합니다. 이 선택은 남아 있는 Store판에서 사용하는 공유 설정·프리셋·스킨에도 영향을 줍니다.
공유 데이터를 직접 삭제하려면 양쪽 앱을 모두 종료한 뒤 Windows의 Saved Games에 있는 DMeloper's Block Pet 폴더를 삭제할 수 있습니다. 관련 데이터를 삭제하면 저장한 설정·프리셋·스킨을 사용할 수 없게 됩니다. 삭제 범위나 경로 확인에 도움이 필요하면 아래 문의처로 연락해 주세요.
■ 7. 정보 제공과 사용자 선택
사용자는 닉네임 조회와 OBS 출력을 사용하지 않고 로컬 PNG 또는 기본 스킨으로 앱을 사용할 수 있습니다. OBS 출력은 설정에서 끌 수 있습니다. 마우스 사용을 끄면 마우스 물체와 클릭·스크롤 반응이 꺼지지만, 커서를 따라보는 동작은 유지됩니다. 모든 입력 감지를 중단하려면 앱을 완전히 종료해 주세요. 저장된 프리셋을 로컬 파일로 내보내거나 관련 로컬 데이터를 삭제할 수 있습니다.
개발자는 앱의 저장된 설정·스킨을 원격으로 조회하거나 변경하지 않습니다. 개인정보 관련 열람·정정·삭제 요청 또는 문의는 아래 이메일로 보내 주세요. 개발자가 보유하지 않는 로컬 데이터는 사용자의 컴퓨터에서 직접 관리해야 하므로 필요한 방법을 안내할 수 있습니다.
사용자가 개발자에게 이메일로 문의하면 이메일 주소, 문의 내용과 자발적으로 첨부한 자료를 받습니다. 이 정보는 문의 응답과 요청 처리에 필요한 범위에서 이용하고, 처리에 필요한 기간 동안 보관합니다. 문의 처리 목적이 끝난 정보는 삭제하며, 관련 법령에 따라 보관이 필요한 경우에는 해당 기간 동안 보관합니다. 문의 시 비밀번호, 인증 토큰, OBS 연결 주소 등 요청 처리에 필요하지 않은 정보는 보내지 마세요.
