# 데이터·권한 안내

한국어 · [English](PRIVACY.md)

DMeloper's Block Pet에서 사용하는 데이터와 권한을 안내합니다.

앱은 계정 서비스나 사용 분석 기능을 제공하지 않으며, 충돌 보고서를 자동으로 업로드하지 않습니다. Java Edition 스킨 조회, 업데이트 확인과 직접 여는 외부 페이지는 네트워크를 사용합니다. 자세한 내용은 아래에서 확인할 수 있습니다.

## 키보드와 마우스

앱은 키를 누르고 떼는 동작, 포인터 위치, 마우스 버튼과 스크롤을 감지해 펫을 움직입니다. 현재 눌린 키를 임시로 관리하며 접촉 위치와 입력 강도로 동작을 표현합니다.

입력한 문장과 입력 이력은 저장하거나 서버에 전송하지 않습니다. 포인터와 버튼 상태도 이 컴퓨터에서 처리합니다. 앱을 종료하면 입력 감지가 중단됩니다. 설정에서 마우스 물체와 클릭·스크롤 반응을 끌 수 있지만, 포인터를 따라보는 동작은 유지됩니다.

## OBS 브라우저 출력

방송 출력은 기본으로 꺼져 있습니다. 켜면 이 컴퓨터의 `127.0.0.1`에만 HTTP/WebSocket 서버가 열립니다. 연결 주소를 가진 브라우저 소스에 현재 장면·활성 PNG 스킨·동작 이벤트를 전달합니다. 여기에는 물리적인 키 위치, 누름·뗌 상태와 타이밍이 포함되므로 주소를 가진 사람이 누른 키나 입력 활동을 추정할 수 있습니다. 입력한 문장, 스킨 목록 이름이나 다른 파일은 전달하지 않습니다. 공개 서버를 사용하지 않으며 녹화·송출은 OBS 등의 프로그램이 관리합니다.

데스크톱 펫을 숨겨도 방송 출력은 계속됩니다. 방송 출력을 끄면 소스 연결이 끊깁니다. 연결 주소에는 임의 접근 토큰이 포함되며 복사 시 클립보드에 기록됩니다. 주소를 비공개로 보관하세요. OBS 소스의 주소가 바뀌지 않도록 포트와 토큰은 이 컴퓨터에 저장하며 프로그램 초기화 후에도 유지합니다. 초기화하면 방송 출력은 꺼집니다.

## 스킨과 네트워크

직접 선택한 PNG를 읽어 복사본과 미리보기를 스킨 목록에 저장합니다. 표시 이름, 확인 가능한 원래 파일명과 팔 모델도 함께 저장합니다. 눈썹·손바닥 색상은 개별 스킨 목록 항목이 아니라 프리셋에 저장합니다. 이 과정에서 스킨을 개발자나 스킨 서비스에 업로드하지 않습니다.

Java Edition 닉네임을 적용하면 `api.minecraftservices.com` 또는 지원되는 대체 경로인 `api.mojang.com`에 닉네임을 전송합니다. 공개 프로필 ID로 `sessionserver.mojang.com`을 조회하고 `textures.minecraft.net`에서 HTTPS로 PNG를 받습니다. 이 서비스에는 요청과 접속에 사용한 네트워크 주소가 전달됩니다. 프록시를 사용하면 프록시 주소가 전달될 수 있습니다. 각 서비스의 개인정보 정책이 적용됩니다. Microsoft/Xbox 토큰이나 비밀번호를 요청하지 않습니다. Bedrock·Marketplace 콘텐츠는 지원하지 않습니다. 조회할 수 있는 스킨이라도 사용·공유 권한이 자동으로 부여되지는 않습니다. 스킨 원작자의 권리를 확인하세요.

확인한 PNG와 공식 프로필의 닉네임은 다시 사용할 수 있도록 이 컴퓨터에 저장합니다. 스킨 목록에는 현재 선택한 스킨 외의 항목도 남아 있을 수 있습니다. 다운로드한 원본 PNG의 별도 캐시는 최대 32 MiB입니다. 앱을 시작하면 저장된 데이터를 불러오며, 저장한 닉네임을 네트워크에서 자동으로 다시 조회하지 않습니다.

### 프리셋 파일

프리셋 하나를 `.petpreset` 파일로 내보낼 수 있습니다.

- 이미지 방식: PNG, 팔 모델과 연결된 닉네임을 포함합니다.
- 닉네임 방식: 연결된 닉네임을 포함하며 PNG와 스킨 미리보기는 넣지 않습니다.
- 사용자 스킨 제외: 사용자 PNG와 닉네임 대신 기본 PNG와 기본 눈썹·손바닥 색상을 넣습니다.
- 공통: 프리셋 이름과 펫·장면·오브젝트 설정을 포함합니다. 공통 설정·데스크톱 위치·내부 라이브러리 ID는 제외합니다.

내보낼 때는 스킨 서비스를 조회하지 않습니다. 닉네임 파일을 불러올 때 위 공식 조회를 한 번 수행하고 이후 사용할 PNG를 로컬에 저장합니다. 앱은 파일을 로컬에 저장하며 업로드하지 않습니다. 직접 공유하기 전에 포함된 이미지와 닉네임을 확인하세요. 이미지를 포함해 공유하려면 원작자의 허락이나 공유 권한이 필요합니다. 닉네임을 공유해도 연결된 스킨의 이용·공유 권한이 함께 이전되는 것은 아닙니다.

## 로컬 데이터와 삭제

공식 GitHub판과 Store판은 Saved Games\DMeloper's Block Pet에서 설정·프리셋·스킨을 공유합니다. 먼저 실행된 공식 인스턴스가 유지되며 다른 설치가 동시에 데이터를 쓰지 않습니다. 로그·캐시·WebView 데이터는 설치별 AppData에 저장됩니다. 스킨·미리보기·파일명·닉네임·설정은 개인 데이터로 취급하세요.

일반 제거에서는 개인 데이터를 유지합니다. 공식 GitHub판 제거기에서 기본으로 해제된 `모든 개인 설정 및 파일 제거`를 선택하고 확인하면 Saved Games의 공유 설정·프리셋·스킨과 GitHub판의 로컬·로밍 AppData를 삭제합니다. 여기에는 GitHub판의 로그·캐시·WebView 데이터가 포함됩니다. Store판도 같은 Saved Games 데이터를 사용하므로 공유 설정·프리셋·스킨을 함께 잃게 됩니다.

개발판과 시험판은 별도 AppData에 데이터를 저장하며 공식 Saved Games 데이터를 공유하지 않습니다. WiX 시험판의 같은 삭제 옵션은 해당 시험판의 로컬·로밍 AppData만 삭제하며 공식 Saved Games 폴더는 삭제하지 않습니다. 데이터 삭제는 실행 중인 앱을 종료하고 삭제 요청을 확인할 수 있어야 시작합니다. 정리가 실패하면 앱 제거를 중단하며 일부 선택된 파일은 이미 삭제되었을 수 있습니다.

Store판 제거 시 패키지 전용 데이터는 Windows가 관리하며 외부 Saved Games 데이터는 남습니다. 기본 스킨 선택만으로 스킨 목록은 지워지지 않습니다.

## 업데이트

공식 GitHub판에서 설정을 열면 `raw.githubusercontent.com/d-meloper/dmelopers-block-pet/updates/tauri-stable.json`과 분리 서명으로 업데이트를 확인합니다. 확인에 성공한 결과는 6시간, 오류는 10분 동안 보관해 재사용합니다. 수동 확인 버튼을 누르면 새로 조회합니다. GitHub는 요청과 네트워크 주소를 받습니다. 요청에 설정·스킨·입력 이력·방송 주소·장치 식별정보는 넣지 않습니다. 버전 정보와 확인·오류 시각을 로컬에 보관합니다. 릴리즈 링크를 직접 열면 브라우저를 통해 GitHub에 접속합니다.

GitHub 업데이트 시험판은 별도 `raw.githubusercontent.com/oup030416/dmelopers-block-pet-test/updates/wix-test.json`과 분리 서명을 사용합니다. 로컬 업데이트 시험판은 업데이트 정보와 설치파일을 이 컴퓨터의 `127.0.0.1:17831`에서만 받습니다.

업데이트 설치 버튼을 누르면 해당 설치판에 정해진 출처에서 설치파일을 다운로드·검증하고 설정을 저장한 뒤 설치를 시작합니다. 설정 저장이 시작되기 전까지 취소할 수 있습니다. 앱이 개인 데이터를 이전 백업으로 자동 복원하지는 않습니다. 설치 중단 시 앱을 종료하고 같은 설치파일을 다시 실행해 프로그램 파일을 복구하세요.

Store판은 Windows가 업데이트를 관리하며 Store 열기 버튼을 제공합니다. GitHub 업데이트 정보나 별도의 GitHub 버전 표시 정보는 요청하지 않습니다. Store 열기 버튼은 Store 앱을 통해 Microsoft 서비스에 연결합니다. 두 배포판의 입력·펫·OBS 기능은 같습니다. 자동 시작은 설치별로 설정하며 먼저 시작한 공식 인스턴스가 유지됩니다. 프리셋 불러오기는 완료 또는 복구 확인 전까지 자체 복구 기록을 보존하며 전체 앱 데이터 내보내기·가져오기는 제공하지 않습니다.

## 로그·클립보드·시스템

앱 정보 화면에서 로그 폴더를 열 수 있습니다. 새 진단 파일 기록에는 분류된 경고·오류, 동작 이름, 오류 코드, 제한된 소스 위치, 시각, 앱 버전, 실행 유형과 프로세스 ID가 포함됩니다. 원문 오류 메시지, 설정, 개인 파일 경로, 스킨, 닉네임과 방송 연결 주소는 저장하지 않으며, 정상적인 입력 활동도 기록하지 않습니다.

앱은 하나의 로컬 진단 파일에 기록을 추가하고 반복 메시지를 제한합니다. 로그를 자동으로 업로드하거나 여러 파일로 나누거나 삭제하지 않으며, 종료나 초기화로도 삭제하지 않습니다. 이전 기록이 남을 수 있으므로 공유할 부분을 먼저 검토하고, 개인 경로·로컬 데이터·스킨·닉네임·인증정보는 공개 이슈에 올리지 마세요.

화면 스포이드를 사용하면 색상을 선택하는 동안 연결된 화면 전체를 메모리에 임시 캡처합니다. 캡처 이미지는 저장하거나 전송하지 않으며 선택이 끝나면 해제합니다. 선택한 RGB 색상만 외형 설정에 적용합니다.

앱 정보 복사 버튼은 앱·런타임·WebView2 버전, 배포판 종류, Windows 에디션·버전·빌드, 그래픽 렌더러, 화면 크기·배율, 렌더링 옵션과 펫·방송 출력 상태를 클립보드에 기록합니다. 개인 경로, 스킨·프리셋 내용, 닉네임과 방송 연결 주소는 제외합니다. 공유하기 전에 복사한 환경 정보를 확인하세요. 창 관리, 설정한 전역 단축키, 선택적 로그인 시 자동 시작을 사용합니다. 자동 시작은 설정에서 끌 수 있습니다. GitHub 설치 프로그램은 WebView2가 없으면 포함된 Microsoft 서명 설치 도구를 실행합니다. 이 도구는 Microsoft 서비스에서 런타임을 다운로드하고 설치하며, 해당 서비스는 요청과 네트워크 주소를 받습니다. 앱 자체는 WebView2 설치 도구를 다운로드하거나 실행하지 않습니다. Store판에서 런타임이 없거나 설치 후에도 사용할 수 없으면 앱이 수동 설치 안내를 제공합니다. 외부 링크는 브라우저로 열며 해당 사이트의 정책이 적용됩니다.
