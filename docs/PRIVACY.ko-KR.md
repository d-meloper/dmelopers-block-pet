# 개인정보 및 권한

이 문서는 현재 소스 미리보기의 구현을 설명합니다. 공식 설치파일과 Store 제품은 아직 공개하지 않았습니다.

DMeloper's Block Pet에는 개발자 계정 서비스·사용 분석·자동 충돌 보고 업로드가 없습니다. Java Edition 스킨 조회, 최신 버전 확인과 사용자가 여는 외부 페이지는 아래와 같이 네트워크를 사용합니다.

## 키보드와 마우스

전역 입력 감시는 눌림·떼기, 포인터 위치, 마우스 버튼과 스크롤을 펫의 동작에 사용합니다. 네이티브 코드가 현재 키 상태를 임시로 관리하고 렌더러에는 접촉 위치와 입력 강도를 전달합니다. 입력한 문장과 입력 이력은 저장하거나 서버에 전송하지 않습니다. 포인터와 버튼 상태는 로컬에서 처리합니다. 앱을 종료하면 감시가 중단되며 마우스 상호작용은 설정에서 끌 수 있습니다.

## 선택적 OBS 브라우저 출력

방송 출력은 기본으로 꺼져 있습니다. 켜면 이 컴퓨터의 `127.0.0.1`에만 HTTP/WebSocket 서버가 열립니다. 연결 주소를 가진 브라우저 소스에 현재 장면·활성 PNG 스킨·동작 이벤트를 전달합니다. 여기에는 물리적인 키 위치, 누름·뗌 상태와 타이밍이 포함되므로 주소 보유자가 키나 입력 활동을 추정할 수 있습니다. 조합된 문장 문자열, 스킨 목록 이름이나 다른 파일은 전달하지 않습니다. 공개 서버를 사용하지 않으며 녹화·송출은 OBS 등의 프로그램이 관리합니다.

데스크톱 펫을 숨겨도 방송 출력은 계속됩니다. 방송 출력을 끄면 소스 연결이 끊깁니다. 연결 주소에는 임의 접근 토큰이 포함되며 복사 시 클립보드에 기록됩니다. 주소를 비공개로 보관하세요. 포트와 토큰은 로컬에 저장되며 프로그램 초기화 후에도 유지되지만 초기화는 방송 출력을 끕니다.

## 스킨과 네트워크

선택한 PNG의 원본·미리보기, 이름·원래 파일명, 팔 모델과 외형 설정을 로컬 스킨 목록에 저장합니다. 로컬 PNG 선택은 스킨 업로드를 하지 않습니다.

Java Edition 닉네임을 적용하면 `api.minecraftservices.com` 또는 지원되는 대체 경로인 `api.mojang.com`에 닉네임을 전송합니다. 공개 프로필 ID로 `sessionserver.mojang.com`을 조회하고 `textures.minecraft.net`에서 HTTPS로 PNG를 받습니다. 이 서비스는 요청과 연결 주소를 받으며 자체 개인정보 정책이 적용됩니다. Microsoft/Xbox 토큰이나 비밀번호를 요청하지 않습니다. Bedrock·Marketplace 콘텐츠는 지원하지 않습니다.

검증한 PNG와 정규화한 닉네임을 로컬에 보관합니다. 다운로드 원본 캐시는 32 MiB 한도이며 앱 시작은 로컬 데이터를 복원하고 닉네임을 자동 재조회하지 않습니다.

프리셋 하나를 `.petpreset` 파일로 내보낼 수 있습니다. 이미지 방식에는 PNG·팔 모델·연결된 닉네임이, 닉네임 방식에는 PNG나 스킨 미리보기 없이 연결된 닉네임이 들어갑니다. 두 방식 모두 프리셋 이름과 펫·장면·오브젝트 설정을 포함하며 공통 설정·데스크톱 위치·내부 라이브러리 ID는 제외합니다. 내보낼 때는 스킨 서비스를 조회하지 않습니다. 닉네임 파일을 불러올 때 위 공식 조회를 한 번 수행하고 이후 사용할 PNG를 로컬에 저장합니다. 앱은 파일을 로컬에 저장하며 업로드하지 않습니다. 직접 공유하기 전에 포함된 이미지와 닉네임을 확인하세요.

## 로컬 데이터와 삭제

공식 GitHub판과 Store판은 Saved Games\DMeloper's Block Pet에서 설정·프리셋·스킨을 공유합니다. 먼저 실행된 공식 인스턴스가 유지되며 다른 설치가 동시에 데이터를 쓰지 않습니다. 로그·캐시·WebView 데이터는 설치별 AppData에 저장됩니다. 테스트·개발판은 데이터가 분리됩니다. 스킨·미리보기·파일명·닉네임·설정은 개인 데이터로 취급하세요.

제거해도 공유 데이터는 유지합니다. 스킨 목록에서 저장 항목을 삭제할 수 있습니다. 프로그램 초기화는 설정·스킨 목록을 지우지만 모든 캐시·로그 삭제를 보증하지 않습니다. 공유 데이터를 직접 지우려면 두 공식 설치를 모두 종료하고 필요한 자료를 보존하세요. 기본 스킨 선택만으로 목록은 지워지지 않습니다.

## 프로그램 버전 관리

공식 GitHub판에서 설정을 열면 `raw.githubusercontent.com/d-meloper/dmelopers-block-pet/updates/tauri-stable.json`과 분리 서명으로 업데이트를 확인합니다. 성공은 6시간, 오류는 10분 동안 캐시하며 수동 확인 버튼은 새로 조회합니다. GitHub는 요청과 네트워크 주소를 받습니다. 요청에 설정·스킨·입력 이력·방송 주소·장치 식별정보는 넣지 않습니다. 공개 버전 정보와 오류 시각을 로컬에 보관합니다.

설치는 사용자가 눌러야 시작되며 고정 공식 GitHub 릴리즈의 검증된 설치파일을 다운로드합니다. 설정 저장이 시작되기 전까지 취소할 수 있습니다. 업데이트용 백업·자동 롤백은 제공하지 않습니다. 설치 중단 시 앱을 종료하고 같은 설치파일을 다시 실행해 프로그램 파일을 복구하세요.

Store판은 Windows가 업데이트를 관리하며 Store 열기 버튼을 제공합니다. GitHub 업데이트 피드나 표시 전용 GitHub 버전 피드를 요청하지 않습니다. Store 열기 버튼은 Store 앱을 통해 Microsoft 서비스에 연결합니다. 두 배포판의 입력·펫·OBS 기능은 같습니다. 자동 시작은 설치별로 설정하며 먼저 시작한 공식 인스턴스가 유지됩니다. 프리셋 불러오기는 완료 또는 복구 확인 전까지 자체 복구 기록을 보존하며 전체 앱 데이터 내보내기·가져오기는 제공하지 않습니다.

## 로그·클립보드·시스템

정보 화면에서 로그 폴더를 열 수 있습니다. 로그에는 환경 정보나 경로가 있을 수 있으므로 공유 전에 개인정보를 제거하세요. 자동 로그 업로드는 없습니다. 로그의 회전·보존은 포함된 로깅 구성요소를 따르며 종료나 초기화 직후 삭제된다고 가정하지 마세요.

앱 정보 복사 버튼은 앱·런타임 버전과 OS 정보를 클립보드에 기록합니다. 창 관리, 설정한 전역 단축키, 선택적 로그인 시 자동 시작을 사용합니다. 자동 시작은 설정에서 끌 수 있습니다. 설치 프로그램은 WebView2가 없으면 공식 수동 설치 주소를 안내하며, 다운로드하거나 설치하지 않습니다. 외부 링크는 브라우저로 열며 해당 사이트의 정책이 적용됩니다.

비공개 보안 제보는 [보안 정책](SECURITY.ko-KR.md), 일반 문의는 [지원 안내](SUPPORT.ko-KR.md)를 확인하세요.
