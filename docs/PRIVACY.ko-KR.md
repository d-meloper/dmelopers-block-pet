# 개인정보와 데이터 안내

한국어 · [English](PRIVACY.md)

DMeloper's Block Pet의 개인정보와 데이터 안내는 노션에서 관리합니다.

- [개인정보 처리방침](https://aismash.notion.site/3f12dc0bb4ae809fb5becfc2376d4a5c): 정보 처리, 외부 서비스와 개인정보 문의 안내.
- [데이터 관리 안내](https://aismash.notion.site/0342dc0bb4ae831581878180c15c0059): 데이터 저장, 프리셋, 초기화·제거 시 삭제 범위와 문의 양식 데이터 안내.

## 펫 자동 숨기기

펫 자동 숨기기는 기본으로 꺼져 있습니다. 앱을 등록하고 기능과 데스크톱 펫 표시를 켜면 현재 활성 창의 실행 파일 경로, 창 식별자, 프로세스 ID와 생성 시각, 표시·최소화 상태를 확인합니다. 일부 Store 앱은 하위 창의 종류도 확인합니다. 비교를 위해 등록하지 않은 활성 앱도 확인할 수 있습니다. 이 기능은 화면을 캡처하거나 창 제목·문서 내용·현재 브라우저 탭 주소·방문 이력을 읽지 않습니다. 기능을 끄거나 등록 목록을 비우거나 데스크톱 펫 표시를 끄거나 앱을 종료하면 확인이 중단됩니다. 자동 숨김 중에는 계속 확인하며 OBS 출력은 유지됩니다.

앱 선택 목록은 Windows 앱 등록 정보, 설치된 패키지 정보, 시작 메뉴·바탕화면 바로가기와 로컬 Windows 검색 인덱스의 프로그램 바로가기 정보를 읽습니다. 이름·아이콘·경로·바로가기 대상·앱 식별 정보·실행 옵션은 메모리에서 처리하며, 등록 목록을 표시할 때도 선택한 실행 파일의 이름·아이콘을 다시 읽을 수 있습니다. 바로가기를 실행하거나 복구하지 않습니다. 사용 여부와 등록한 실행 파일 경로만 Saved Games의 공통 설정에 저장하며 프리셋에는 넣지 않습니다. 조회한 목록·검색어·실행 정보·활성 앱 확인 이력은 앱의 파일이나 진단 로그에 저장하거나 개발자·분석 서비스에 업로드하거나 OBS 소스로 보내지 않습니다. 네트워크 드라이브·공유폴더 또는 리디렉션된 저장 위치를 사용하면 파일 선택·이름 및 아이콘 조회·설정 저장에 해당 저장 서비스가 관여할 수 있으며 그 서비스의 정책이 적용됩니다.

기능을 끄거나 정상 업데이트·일반 제거를 해도 등록 경로는 남습니다. 항목을 제거하면 해당 경로가 현재 목록에서 빠집니다. 자동 숨기기·일반 설정 초기화와 프로그램 설정 전체 초기화는 목록을 비웁니다. 설정이 정상 저장되면 저장 목록에도 반영됩니다. GitHub 제거기의 **모든 개인 설정 및 파일 제거**는 Store판과 공유하는 등록 목록도 삭제합니다. 작업별 범위는 [지원 안내](SUPPORT.ko-KR.md#펫-자동-숨기기)를 확인하세요. 경로와 바로가기 정보에는 사용자명·개인 폴더명이 포함될 수 있으므로 파일이나 화면을 공유하기 전에 확인하세요.
