# 보안 정책

취약점은 [GitHub 비공개 취약점 보고](https://github.com/d-meloper/dmelopers-block-pet/security/advisories/new)로 제보해 주세요. 영향받는 버전, 영향 범위, 재현 절차와 개인정보를 제거한 근거를 포함해 주세요. 공개 이슈에 공격 방법이나 비밀 정보를 올리지 마세요.

Windows 11 24H2 이상 x64의 최신 공개 stable 버전을 대상으로 보안 수정합니다. 최신 버전에서도 재현되는지 확인해 주세요.

앱에서 연결하는 공식 Releases 페이지에서 설치파일을 받으세요. 각 릴리스에는 설치파일과 Tauri 분리 서명(`.sig`), 두 파일의 SHA-256을 제공합니다. 업데이트는 수동 설치하며 앱이 업데이트 패키지를 가져오거나 실행하지 않습니다. 첫 공개판에는 Authenticode 서명이 없어 Windows가 알 수 없는 게시자 안내를 표시할 수 있습니다. 체크섬은 바이트 변경을 확인하며 단독으로 게시자를 인증하지는 않습니다.
