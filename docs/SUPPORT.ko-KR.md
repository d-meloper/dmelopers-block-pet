# 지원 안내

일반 문의·버그·기능 제안은 [GitHub Issues](https://github.com/d-meloper/dmelopers-block-pet/issues)를 이용해 주세요. Windows 11 24H2 이상 x64를 지원합니다. WebView2가 필요하며 없는 경우 설치 프로그램이 다운로드할 수 있습니다.

앱 버전, 정확한 설치 파일 이름, Windows 버전, 화면 배율, 재현 절차와 기대 동작을 알려 주세요. 첨부 자료에서 개인 경로·닉네임·스킨·토큰 등 개인정보를 제거해 주세요.

[Releases](https://github.com/d-meloper/dmelopers-block-pet/releases/latest)의 설치 파일을 사용하고 현재 사용자 또는 모든 사용자 설치를 선택하세요. 설정 > 정보에서 업데이트를 확인하고 릴리즈 노트를 볼 수 있습니다. 업데이트는 이전 프로그램과 설정을 임시로 보관하고, 정상 완료 확인 후 사본을 삭제합니다.

업데이트에 실패하면 이전 상태로 자동 복구하고, 실패 이유와 복구 결과를 모달로 안내합니다. 복구를 완료하지 못한 경우 필요한 임시 사본을 보존합니다. 공유할 진단 자료에서 개인정보를 제거하세요. 취약점은 [보안 정책](SECURITY.ko-KR.md)을 따라 비공개로 제보해 주세요.
