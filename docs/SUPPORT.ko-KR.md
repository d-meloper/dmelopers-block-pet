# 지원

문의·버그·기능 제안은 [GitHub Issues](https://github.com/d-meloper/dmelopers-block-pet/issues)를 이용하세요. DMeloper's Block Pet은 Windows 11 24H2 이상 x64용 무료 독립 개인 프로젝트이며 한국어와 영어를 제공합니다. Microsoft WebView2가 필요합니다. 없으면 앱 또는 설치기가 Microsoft 공식 수동 설치 페이지를 열고 재시도·종료를 안내합니다. bootstrapper를 다운로드하지 않습니다.

GitHub 설치는 현재 사용자만 지원합니다. 설정 > 정보에서 서명된 업데이트 정보를 확인하며 설치는 사용자가 눌러야 시작합니다. 설정 저장이 시작되기 전까지 취소할 수 있습니다. 종료 요청 시 앱을 정상 종료하세요. 설치 중단 시 같은 설치파일을 다시 실행해 복구하며 자동 롤백은 제공하지 않습니다. Store 설치·업데이트는 Windows가 관리하며 정보 화면에서 Store 페이지를 엽니다.

공식 GitHub판과 Store판은 Saved Games\DMeloper's Block Pet의 설정·프리셋·스킨을 공유합니다. 제거해도 공유 데이터는 보존됩니다. 설치별 AppData에는 로그·캐시·WebView 데이터가 있습니다. 자동 시작은 설치별로 설정하며 두 설치가 시작되면 먼저 실행된 공식 인스턴스가 유지됩니다. 테스트·개발 데이터는 별도로 저장됩니다.

앱 버전·배포 경로·설치 방법(새 설치 또는 업데이트)·해당하는 경우 설치파일명·Windows 버전·화면 배율·재현 절차를 적어 주세요. 관련 진단 로그가 있으면 개인 경로·스킨·닉네임·토큰 등 개인정보를 제거한 부분만 첨부하세요. 비공개 보안 제보는 [보안 안내](SECURITY.ko-KR.md)를 따르세요.
