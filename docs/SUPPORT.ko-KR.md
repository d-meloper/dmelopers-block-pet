# 지원 안내

한국어 · [English](SUPPORT.md)

## 설치 도움말

[Microsoft Store](https://apps.microsoft.com/detail/9PLKW6NBMKQ7?hl=ko-KR)에서 설치하거나 [GitHub 릴리즈 페이지](https://github.com/d-meloper/dmelopers-block-pet/releases)에서 `.exe` 설치파일을 받으세요. 함께 제공하는 `.sig` 파일은 검증용이므로 일반 설치 시 별도로 받지 않아도 됩니다. GitHub판은 현재 Windows 계정에 설치됩니다.

DMeloper's Block Pet의 최소 환경은 x64 Windows 10 22H2 + 2023년 9월 누적 업데이트(빌드 19045.3448) 이상입니다. Windows 11은 22H2 + 2023년 9월 누적 업데이트(빌드 22621.2283) 이상이 필요합니다. Windows 11 24H2(빌드 26100) 이상을 권장하며, 앱은 한국어와 영어를 지원합니다.

앱과 WiX 설치 프로그램의 최소 환경 경고는 확인 후 계속 진행할 수 있지만, 미지원 환경의 동작은 보장하지 않습니다. 매우 오래된 Windows에서는 경고를 표시하기 전 프로그램 로딩부터 실패할 수 있습니다. Store 패키지에는 최소 설치 버전 `10.0.19045.3448`을 설정했습니다. Windows 11에서는 앱이 위 Windows 11 최소 환경도 확인합니다.

Microsoft WebView2 Runtime이 필요합니다. 120 이상이 없으면 WiX 설치 프로그램이 확인된 Microsoft 설치 도구를 실행해 설치하며, 이 과정에는 인터넷 연결이 필요합니다. 설치가 실패하면 앱에서 여는 Microsoft 설치 페이지를 통해 직접 설치한 뒤 다시 시도하세요. 종료하고 나중에 다시 진행할 수도 있습니다.

## 업데이트와 복구

GitHub판은 설정 > 정보에서 공식 저장소의 서명된 업데이트 정보를 확인합니다. 업데이트 버튼을 누르면 설치를 시작하며 설정 저장이 시작되기 전까지 취소할 수 있습니다. 앱은 설치를 시작하기 전에 설치파일을 검증합니다.

WiX 설치에서 앱 종료 안내가 나오면 정상적으로 종료하세요. 설치가 중단되었다면 같은 설치파일을 다시 실행해 프로그램 파일을 복구하세요. Windows Installer가 프로그램 파일 변경의 롤백을 처리하며, 앱이 개인 데이터를 이전 백업으로 자동 복원하지는 않습니다.

Microsoft Store판은 Windows가 설치와 업데이트를 관리하도록 구성되어 있습니다. 정보 화면에서 Store 페이지 또는 다운로드와 업데이트 페이지를 열 수 있습니다. Windows 11 24H2 이상에서는 실행 중인 앱의 Store 업데이트를 연기합니다. 그 이전 지원 버전은 해당 Windows의 기본 Store 업데이트 동작을 따릅니다. 업데이트를 적용하기 전 트레이 메뉴에서 앱을 완전히 종료하세요. 앱을 다시 시작하는 것만으로 업데이트 적용을 보장하지는 않습니다.

다운로드 경고, 체크섬과 서명에 관한 내용은 [보안 안내](SECURITY.ko-KR.md)를 확인하세요.

## 설정과 스킨

데이터 저장 위치와 초기화·제거 시 삭제 범위는 [데이터 관리 안내](https://aismash.notion.site/0342dc0bb4ae831581878180c15c0059), 정보 처리와 문의 양식 데이터는 [개인정보 처리방침](https://aismash.notion.site/3f12dc0bb4ae809fb5becfc2376d4a5c)을 확인하세요. 두 안내는 노션에서 관리합니다.

## 전체화면 게임

전체화면 게임에서는 ‘항상 위에 표시’를 켜도 펫이 보이지 않을 수 있습니다. 게임의 표시 모드를 창모드 또는 테두리 없는 창모드로 설정해주세요.
