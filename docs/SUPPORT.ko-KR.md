# 지원 안내

한국어 · [English](SUPPORT.md)

## 설치 도움말

DMeloper's Block Pet은 Windows 11 24H2(빌드 26100) 이상 x64에서 사용할 수 있으며 한국어와 영어를 지원합니다.

[릴리즈 페이지](https://github.com/d-meloper/dmelopers-block-pet/releases)에서 설치파일을 받으세요. GitHub판은 현재 Windows 계정에 설치됩니다.

Microsoft WebView2 Runtime이 필요합니다. 설치되어 있지 않으면 앱이나 설치 프로그램에서 Microsoft 설치 페이지를 엽니다. 설치를 마친 뒤 재시도를 누르세요. 종료하고 나중에 다시 진행할 수도 있습니다. WebView2는 자동으로 다운로드하거나 설치하지 않습니다.

## 업데이트와 복구

GitHub판은 설정 > 정보에서 업데이트를 확인할 수 있습니다. 서명된 업데이트 정보를 확인하고, 업데이트 버튼을 누르면 설치를 시작합니다. 설정 저장이 시작되기 전까지 취소할 수 있습니다.

앱 종료 안내가 나오면 정상적으로 종료하세요. 설치가 중단되었다면 같은 설치파일을 다시 실행해 프로그램 파일을 복구하세요. 이전 버전으로 자동 복원하는 기능은 제공하지 않습니다.

Microsoft Store판은 Windows가 설치와 업데이트를 관리합니다. 정보 화면에서 Store 페이지를 열 수 있습니다.

다운로드 경고, 체크섬과 서명에 관한 내용은 [보안 안내](SECURITY.ko-KR.md)를 확인하세요.

## 설정과 스킨

공식 GitHub판과 Store판은 `Saved Games\DMeloper's Block Pet`의 설정·프리셋·스킨을 공유합니다. 기본 GitHub판 제거에서는 공유 데이터와 설치별 데이터를 유지합니다. GitHub 제거기에서 `모든 개인 설정 및 파일 제거`를 선택하고 확인하면 공유 데이터와 GitHub판 `%LOCALAPPDATA%`·`%APPDATA%` 데이터를 삭제합니다. 이 경우 설치된 Store판의 공유 설정·프리셋·스킨도 함께 사라집니다. Store판 제거는 Windows가 관리해 패키지 전용 데이터를 제거하며, 외부 Saved Games 공유 데이터는 유지됩니다.

로그·캐시·WebView 데이터는 설치별 AppData에 저장됩니다. 자동 시작도 설치별로 설정하며, 두 공식 설치가 시작되면 먼저 실행된 앱이 유지됩니다.

데이터 사용과 삭제 방법은 [데이터·권한 안내](PRIVACY.ko-KR.md)를 확인하세요.

## 문의와 버그 제보

문의, 버그 제보, 기능 제안은 [GitHub Issues](https://github.com/d-meloper/dmelopers-block-pet/issues)를 이용하세요. 다음 정보를 함께 적어 주시면 도움이 됩니다.

- 앱 버전과 사용 중인 배포판: GitHub, Microsoft Store 또는 직접 빌드한 앱
- 새 설치·업데이트·재설치 여부와 해당하는 경우 이전 버전
- 설치파일명, Windows 버전과 화면 배율
- 문제가 발생하는 과정, 예상한 동작과 실제 동작

관련 진단 로그가 있으면 필요한 부분만 첨부해 주세요. 개인 경로·스킨·닉네임·토큰 등 개인정보는 먼저 지워 주세요.

취약점은 [보안 안내](SECURITY.ko-KR.md)에 따라 비공개로 제보해 주세요.
