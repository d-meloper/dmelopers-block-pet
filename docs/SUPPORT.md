# Support

Use [GitHub Issues](https://github.com/d-meloper/dmelopers-block-pet/issues) for ordinary questions, bugs and feature requests. This release supports Windows 11 24H2 or newer, x64. WebView2 is required and the installer can download it when absent.

Include the app version, exact installer filename, Windows version, display scaling, steps to reproduce and expected behavior. Remove personal paths, nicknames, skins, tokens and other private information from attachments.

Use the installer from [Releases](https://github.com/d-meloper/dmelopers-block-pet/releases/latest). Choose current-user or all-users installation as needed. In Settings > About you can check for updates and read release notes. Updates temporarily save the previous program and settings, then delete those copies after successful verification.

If an update fails, the app automatically restores its previous state and shows the failure reason and recovery result in a dialog. If recovery cannot finish, its temporary copies are preserved. Provide only sanitized diagnostics. For confidential vulnerability reports, follow [Security](SECURITY.md).
