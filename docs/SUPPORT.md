# Support

Use [GitHub Issues](https://github.com/d-meloper/dmelopers-block-pet/issues) for questions, bugs and suggestions. DMeloper's Block Pet is a free independent personal project for Windows 11 24H2 or newer x64, available in Korean and English. Microsoft WebView2 is required. If absent, the app or installer opens Microsoft's official manual installation page and lets you retry or exit; it never downloads a bootstrapper.

GitHub installs are current-user only. In Settings > About, checking retrieves signed update information, and installation starts only after your click. You can cancel until settings saving begins. Close the app normally when asked; an interrupted installation is repaired by running the same installer again. Automatic rollback is not provided. Store installation and updates are managed by Windows; About opens the Store listing.

Settings, presets and skins are shared by the official GitHub and Store installations in Saved Games\DMeloper's Block Pet. Uninstall preserves that shared data. Per-install AppData contains logs, caches and WebView data. Start-at-login is configured separately for each installation; when both start, the first official instance keeps running. Test and development data remain separate.

Include app version, distribution channel, installation method (new installation or update), installer filename where applicable, Windows version, display scaling and reproduction steps. If available, include the relevant diagnostic log excerpt after removing personal paths, skins, nicknames, tokens and other private information. Use [Security](SECURITY.md) for confidential reports.
